# TPL Implementation Plan

*Source: OpenAI strategic analysis, March 2026*
*Added to vault by Hermes, March 31, 2026*

---

## Design Principle

**Do not organize the think tank around issues. Organize it around capacities.**

Third Period Labs should build a coherent platform around three student capacities that make learning and citizenship possible: literacy, executive function, and epistemic capacity. Treat attendance/engagement and teacher implementation conditions as structural amplifiers rather than separate coequal crises.

---

## 1. The Governing Framework

**The Three-Capacity Crisis**
- Literacy
- Executive Function
- Epistemic Capacity

**Structural Amplifiers**
- Chronic absenteeism / disengagement
- Teacher capacity / implementation quality
- Attention economy / device environment

### Deliverable in first 30 days

Write a short founding white paper:

**The Three-Capacity Crisis: A Teacher-Led Framework for Educational Recovery and Democratic Readiness**

It should:
- Define each capacity in plain language and research language
- Show how the capacities interact
- Distinguish capacity measures from state accountability labels
- Identify the structural amplifiers that distort all three

---

## 2. Build the Measurement Spine

### A. Literacy Measurement System

**Layer 1: Independent national signal** — NAEP and related national trend data as the hard external benchmark.

**Layer 2: Timely recovery signal** — NWEA and similar national interim-trend datasets for stalled recovery and floor effects.

**Layer 3: State reporting signal** — Track state proficiency rates, but never treat them as the same as independent mastery.

### B. Executive Function Measurement System

Build a **proxy dashboard**:
- Chronic absenteeism
- Classroom disruption indicators
- Device policy strength
- Student self-regulation routines
- Survey-based attention and task persistence data
- Student well-being indicators where available

### C. Epistemic Capacity Measurement System

Measure performance on tasks:
- Source evaluation tasks
- Lateral-reading tasks
- Conflict-of-interest detection tasks
- Claim verification tasks
- Civic reasoning tasks linked to online content
- Existing civics achievement baselines (NAEP civics)

---

## 3. Three Workstreams + One Cross-Cutting Lab

### Workstream 1: Literacy and Knowledge Building
Owns early reading, adolescent reading, curriculum coherence, multilingual learner reading supports, and honesty around proficiency signals.

### Workstream 2: Executive Function and School Environment
Owns device policy, routines, cognitive load, attendance, and stress-sensitive school design.

### Workstream 3: Epistemic Capacity and Democratic Readiness
Owns media literacy, civic online reasoning, epistemic trust, and inquiry-rich civic learning.

### Cross-Cutting: Teacher Implementation Lab
- Recruit teacher fellows
- Pilot routines and tools
- Produce "implementation memos" alongside policy briefs
- Ask every time: can a teacher actually do this on Tuesday morning?

---

## 4. First-Year Implementation Agenda

### Phase 1 (First 90 Days): Establish Credibility

**Brief 1: The Reading Honesty Problem**
Show the difference between independent benchmarks and state proficiency signals.

**Brief 2: Attention Under Siege**
Summarize EF evidence carefully. Message: school environments can either worsen or buffer attention fragmentation.

**Brief 3: Can Students Tell What's True?**
Use civic online reasoning and civics data. Include model classroom tasks.

### Phase 2 (Months 4-8): Diagnosis to Design

**Playbook A: K-8 Literacy Recovery Playbook**
Foundational skills, knowledge-building curriculum, comprehension instruction, multilingual scaffolds, intervention systems.

**Playbook B: Executive Function-Friendly School Design**
Phone policy models, transition routines, task chunking, working-memory supports, protected deep work blocks.

**Playbook C: Epistemic Capacity Across the Curriculum**
Weekly source-check routines, lateral reading mini-lessons, historical sourcing, scientific claim verification.

### Phase 3 (Months 9-12): Policy Positioning

Advocate for:
- Honest public reporting on proficiency and cut scores
- Statewide literacy implementation supports
- Strong but workable school-day device policies
- Chronic absenteeism as a central school-quality indicator
- Civic online reasoning embedded into state standards
- Teacher-led pilot grants for implementation testing

## 5. Policy Recommendations by Crisis

### Literacy Policy Package
1. Proficiency transparency laws/regulations
2. Statewide literacy implementation infrastructure
3. Early warning for reading recovery
4. Adolescent literacy revival
5. Knowledge-building over worksheet literacy

### Executive Function Policy Package
1. Bell-to-bell phone restriction models
2. Attendance as cognitive infrastructure
3. Routine-rich school design
4. Stress-sensitive school systems
5. Teacher-friendly implementation

### Epistemic Capacity Policy Package
1. Embed civic online reasoning in standards/curriculum
2. Require task-based assessment of source evaluation
3. Create model cross-subject routines
4. Teach uncertainty tolerance explicitly
5. Avoid partisan branding

---

## 6. Communications Strategy

**Rule 1:** Use high-force language only when data are strongest.
- Literacy: strong alarm language justified
- Executive function: "under siege" / "under strain," not "collapsed"
- Epistemic capacity: "weakened" / "fragile" / "underdeveloped"

**Rule 2:** Always pair diagnosis with instructional hope.

**Rule 3:** Distinguish labels from reality.

**Rule 4:** Speak as teachers, not as pundits. Use classroom language.

---

## 7. Research Agenda (Years 1-3)

1. Which literacy policies survive the implementation cliff?
2. What kind of phone policy is both effective and enforceable?
3. What is the minimum viable epistemic curriculum?
4. How does chronic absenteeism interact with literacy recovery?
5. What classroom routines best support EF without pseudo-neuroscience theater?

---

## 8. Operating Model

### Staff/Fellowship Model
- 1 executive director / lead editor
- 3 issue leads (one per capacity)
- 1 research director
- 1 data and visualization lead
- 8-15 teacher fellows
- Advisory board

### Publication Cadence
- One flagship brief every 6-8 weeks
- One rapid response memo per major data drop
- One implementation playbook each semester
- One annual "capacity report"

### Signature Annual Product
**The Third Period Capacity Index** — state-by-state scorecard with indicators for literacy signal integrity, absenteeism, device environment, civic/source-evaluation readiness, and implementation conditions.

---

## 9. What to Avoid

- Don't let literacy become "phonics explains everything"
- Don't let EF become vague SEL fog or punitive "grit" rhetoric
- Don't let epistemic work get framed as partisan media policing
- Don't treat attendance as secondary
- Don't publish before building citation discipline

---

## 10. Bottom Line

**Third Period Labs should become a teacher-led capacity and implementation institute.**

> "American schooling is not merely struggling with achievement. It is struggling to reliably build the capacities that make achievement, judgment, and democratic life possible."
