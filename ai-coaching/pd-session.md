# AI in the Classroom: Tools That Serve Kids, Not Replace Teachers

## 45-Minute Professional Development Session

**Facilitator:** Matt Walker | Social Studies & ESOL | PWCS
**Audience:** K-12 educators, instructional coaches, content leads
**Format:** Interactive workshop (not a product demo)

---

## Session Objectives

By the end of this session, participants will be able to:

1. Apply an **equity-first filter** when evaluating AI tools for classroom use
2. Distinguish between AI as **scaffold** (builds capacity) and AI as **crutch** (replaces capacity)
3. Design one AI-scaffolded activity for their content area using the **Zwiers academic language framework**
4. Identify **guardrails and exit ramps** for any AI tool they adopt

---

## Materials Needed

- Projector/screen
- Participant devices (laptops or phones)
- Handout: "The Scaffold vs. Crutch Decision Matrix" (provided)
- Handout: "AI Equity Audit — 5 Questions" (provided)
- Sticky notes + markers for gallery walk
- Timer visible to all

## Agenda

### 1. Opening Hook (5 min)

**Activity: "The Paragraph Test"**

Display two versions of the same student writing sample side by side:
- **Version A:** Student's original draft with clear ESOL-influenced syntax
- **Version B:** The same paragraph after AI "corrected" it — grammatically perfect, voice completely erased

Ask: *Which one tells you more about what this student knows? Which one do you want to teach from?*

**Facilitation note:** This is not a gotcha. The point is that AI can erase the diagnostic information teachers need. Let the room sit with the tension. Don't rush to resolve it.

**Key message:** AI is powerful. That's exactly why it requires teacher judgment to deploy well.

---

### 2. Framework: Scaffold vs. Crutch (10 min)

**Mini-lecture + Think-Pair-Share**

Present the core distinction:

| | Scaffold | Crutch |
|---|---|---|
| **Student work** | Student does the thinking | Tool does the thinking |
| **Capacity** | Builds over time | Creates dependency |
| **Teacher role** | Designs the scaffold | Monitors the output |
| **Equity lens** | Lowers barrier to entry | Removes the task entirely |
| **Exit ramp** | Can be gradually removed | Removal = collapse |

**Examples for ESOL/ELL populations:**

- **Scaffold:** AI generates a vocabulary preview in a student's L1, paired with sentence frames for academic output in English. The student accesses content through their strongest language and produces evidence in the target language.
- **Crutch:** AI summarizes a primary source into simplified English. The student reads the summary. The original source — and the comprehension skills it would build — is bypassed.

**Think-Pair-Share prompt (2 min):**
> Think of one tool or practice in your classroom. Is it functioning as a scaffold or a crutch? What would it take to shift it?

**Facilitation note:** Don't police answers. Some teachers will realize they've been using crutches. That's the learning. Judgment-free zone.

---

### 3. The Equity Audit (8 min)

**Activity: 5 Questions Before You Adopt**

Distribute the "AI Equity Audit" handout. Walk through the five questions:

1. **Who benefits most?** If the answer is "students who are already proficient," pause.
2. **Who is left out?** Does it require reading level, device access, or digital literacy that some students don't have?
3. **What language does it assume?** Is it English-only? Does it penalize translanguaging?
4. **What data does it collect?** Who sees it? Does the family know?
5. **What happens when you remove it?** Can the student still do the task? If not, it hasn't built capacity.

**Table discussion (4 min):**
Each table picks one AI tool they've used or been asked to use. Run it through the five questions. Report out: one surprise per table.

**Facilitation note:** This is where the session earns credibility. Teachers are tired of being told to adopt things without being given permission to interrogate them. This gives permission.

---

### 4. Build Session: AI-Scaffolded Activity Design (15 min)

**Activity: Design One Thing You'll Actually Use**

Participants work in content-alike or grade-alike groups to design a single AI-scaffolded classroom activity.

**The template (on handout):**

```
LEARNING TARGET:
What students should know/be able to do

BARRIER THIS ADDRESSES:
What's preventing access (language, reading level, background knowledge, etc.)

AI SCAFFOLD:
What the AI generates or adapts

STUDENT OUTPUT:
What the student still produces themselves

ZWIERS CONNECTION:
Which academic language function does this build?
(Describe, explain, justify, compare, argue, evaluate)

EXIT RAMP:
How do you remove this scaffold over time?
```

**Zwiers quick reference (project on screen):**

| Academic Language Function | What it sounds like |
|---|---|
| **Describe** | "The image shows..." / "The data indicates..." |
| **Explain** | "This happened because..." / "The reason is..." |
| **Justify** | "The evidence supports this because..." |
| **Compare** | "While X..., Y..." / "Both... however..." |
| **Argue** | "I claim that... because... One might counter that..." |
| **Evaluate** | "This source is credible/limited because..." |

**Facilitation notes:**
- Circulate actively. The most common mistake will be designing the AI to do too much. Push back gently: "What is the student's cognitive work here?"
- For ESOL-heavy groups: encourage L1 bridge scaffolds — vocabulary previews, concept maps, or discussion prompts generated in the home language
- Keep the energy practical. This isn't theoretical. They should walk out with something they can use Monday.

---

### 5. Gallery Walk + Shareout (5 min)

Each group posts their activity template on the wall (or shares on screen). Participants do a quick gallery walk with sticky notes:

- **Green sticky:** "I'd steal this for my classroom"
- **Yellow sticky:** "I have a question about..."

Select 2-3 to highlight. Prioritize examples that show strong equity thinking or creative scaffold design.

---

### 6. Close: The Honest Posture (2 min)

**Facilitator remarks (not a script — adjust to your voice):**

Core messages to land:

- AI is changing fast. Nobody has this figured out. Anyone who says they do is selling something.
- The honest posture is **disciplined experimentation**: try it, measure it, adjust. Exactly what good teaching already is.
- Your professional judgment is not replaceable by an algorithm. It is, in fact, the thing that makes AI useful instead of dangerous.
- The goal is not to become "AI teachers." The goal is to remain **great teachers** who use AI when it serves kids.

End with: *You already know how to evaluate whether something works for your students. Trust that. The tool is new. The judgment isn't.*

## Facilitator Notes

**Common pushback and how to handle it:**

| Pushback | Response |
|---|---|
| "My kids just use it to cheat" | "That's a scaffold/crutch design problem, not a student problem. Let's talk about what the task is actually asking them to do." |
| "I don't have time to learn another tool" | "Fair. This session isn't about learning a tool. It's about a framework for evaluating any tool — including deciding not to use one." |
| "Admin is making us use [specific product]" | "Then let's make sure you're using it in a way that actually builds capacity. The equity audit works on mandated tools too." |
| "AI is going to replace teachers" | "AI can generate a lesson plan. It cannot read the room, notice a kid is struggling, or build the relationship that makes a student willing to try something hard. That's you." |

**Session can be extended to 90 min** by adding:
- Live tool exploration (20 min): Participants test-drive an AI tool using the equity audit in real time
- Lesson co-planning (15 min): Pairs co-plan an actual upcoming lesson with AI scaffolds
- Reflection protocol (10 min): Written reflection on what they'll try, what they'll avoid, and what questions remain
